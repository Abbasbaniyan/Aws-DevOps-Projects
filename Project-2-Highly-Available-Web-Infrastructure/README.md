# ☁️ AWS Backup – EC2 & RDS

AWS Backup project demonstrating centralized backup and recovery for **Amazon EC2** and **Amazon RDS MySQL**.

---

## 🚀 Overview

In this project, an EC2 instance and an RDS MySQL database were created and protected using **AWS Backup**.

The project includes:

- EC2 with Nginx and test data
- RDS MySQL with sample database
- AWS Backup Vault
- Daily Backup Plan
- EC2 + RDS Resource Assignment
- On-Demand Backups
- Recovery Point Verification

---

## 🛠️ AWS Services Used

| Service | Purpose |
|---|---|
| EC2 | Linux web server |
| RDS | MySQL database |
| AWS Backup | Backup management |
| IAM | Backup permissions |
| Security Groups | Network security |
| Nginx | Web server |
